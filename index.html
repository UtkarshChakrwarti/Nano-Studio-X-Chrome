Setup · One-time

Running Gemini Nano in your Chrome.

Nano is a small AI model that Chrome runs entirely on your own machine — no servers, no API key, nothing leaves the laptop. Recent desktop Chrome has it built in; it only needs to download the model once.

  1. 01

    Use desktop Chrome 148 or newer

    Check at chrome://version and update if you're older. It works on Windows 10/11, macOS 13+, Linux and Chromebook Plus. Phones, Safari and Firefox can't run it yet.

  2. 02

    Check your machine

    Chrome needs about 22 GB of free disk on the drive holding your Chrome profile, and either a GPU with more than 4 GB of VRAM or 16 GB of RAM with 4+ CPU cores.

  3. 03

    Download the model — once

    Press Download the model in the Engine card (or just send a message). Progress shows right there. It needs an unmetered connection this one time; after that everything works offline.

    To see what Chrome is doing, open:

    chrome://on-device-internals
  4. 04

    On Chrome 138–147: switch on two flags

    Older versions hide the model behind flags. Set the first to Enabled and the second to Enabled BypassPerfRequirement, then press Relaunch:

    chrome://flags/#prompt-api-for-gemini-nano
    chrome://flags/#optimization-guide-on-device-model
  5. 05

    Running your own copy?

    Chrome refuses to give the model to file:// pages. From the project folder, start the bundled server — it listens on your machine only:

    npm start

    Then open http://localhost:8000. No Node? python3 -m http.server 8000 --bind 127.0.0.1 does the same job.

Still stuck? Open Chrome's DevTools console on this page and type await LanguageModel.availability() — unavailable means this machine doesn't meet step 02, downloadable means step 03 is still to do.
