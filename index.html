How to turn on Gemini Nano in your Chrome.

Nano is a small AI model that Chrome can run entirely on your own machine — no servers, no API key, nothing leaves the laptop. It's hidden behind two developer flags. Here's the five-minute walk.

  1. 01

    Use the right Chrome

    You need Chrome 138+ (Stable, Dev, or Canary all work). Check at chrome://version. If you're older, update first.

  2. 02

    Enable the Prompt API flag

    Paste this into Chrome's address bar and hit enter:

    chrome://flags/#prompt-api-for-gemini-nano

    Set the dropdown to Enabled.

  3. 03

    Enable the on-device model flag

    Same drill — paste, then set the dropdown:

    chrome://flags/#optimization-guide-on-device-model

    Set it to Enabled BypassPerfRequirement (the longer option — this lets it run even if Chrome thinks your machine isn't beefy enough).

  4. 04

    Relaunch Chrome

    Click the blue Relaunch button that appeared at the bottom of the flags page. All your tabs come back.

  5. 05

    Force the model to download

    Open this page and wait. The model is ~2 GB and downloads in the background; the first time can take a few minutes:

    chrome://on-device-internals

    Look for status Ready or a filled-in Model path. If it says downloadable but nothing's moving, just open a tab and click "Generate" once — that kicks the download off.

  6. 06

    Serve this file over localhost

    The Prompt API refuses to load from file:// URLs. From the folder containing this HTML, run:

    python3 -m http.server 8000

    Then visit http://localhost:8000/nano-studio.html in Chrome.

Still stuck? Open Chrome's DevTools console on this page and type await window.LanguageModel.availability() — if the answer isn't available, the message tells you which step needs another look.
